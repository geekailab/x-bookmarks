# X Bookmarks

> 在本地同步、搜索、整理和导出你的 X（Twitter）书签，数据完全由你自己掌控。

X Bookmarks 是一个开源浏览器扩展（Chrome MV3）。它把你在 X/Twitter 上的书签完整同步到浏览器本地数据库，并提供本地搜索、文件夹整理、AI 自动分类、媒体下载、多格式导出，以及通过 WebDAV 备份到你自己的网盘的能力。

## ✨ 功能

- **一键同步书签** —— 调用 X 官方接口拉取全部书签（含原生书签文件夹），存入本地 IndexedDB
- **本地搜索** —— 支持关键词与 `from:用户名`、`since:2024-01-01`、`until:2024-12-31` 组合语法
- **文件夹整理** —— 读取 X 原生书签文件夹，按文件夹浏览，自动标记「未分类」
- **AI 自动分类** —— 接入任意 OpenAI 兼容接口（API 地址 / 密钥 / 模型均为自行配置），自动把书签归入文件夹并打标签
- **媒体下载** —— 批量下载书签中的图片 / 视频 / GIF
- **多格式导出** —— 导出为 JSON / CSV / Markdown
- **WebDAV 备份恢复** —— 将书签数据（可选媒体文件）备份到你自己的 WebDAV 网盘，支持同步后自动备份、一键恢复到本地
- **统计面板** —— 图片 / 视频 / GIF / 链接 / 引用 / 长文 / 未分类数量一目了然

## 🔒 隐私

- 书签数据保存在本地浏览器 IndexedDB，**不经过任何第三方服务器**
- 扩展复用你登录 X 时的官方请求凭据调用 X 官方接口，不收集任何账号信息
- AI 分类会把书签文本发送到**你自行配置**的 API；不配置 AI 功能则不会向外部发送内容
- WebDAV 备份只连接你自己的服务器

## 📦 安装

本仓库即扩展成品，无需任何构建，直接本地加载：

1. 下载本仓库（Code → Download ZIP 并解压，或 `git clone`）
2. 打开 Chrome，进入 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择仓库根目录（即包含 `manifest.json` 的目录）

> 兼容 Edge / Brave 等 Chromium 内核浏览器（分别在 `edge://extensions` 等页面按同样方式加载）。

## 🚀 使用

1. 点击工具栏中的扩展图标打开主界面
2. 登录 [x.com](https://x.com) 并打开一次书签页，扩展会自动读取认证信息
3. 回到扩展界面点击「同步书签」，即可把全部书签拉取到本地
4. 顶部搜索框支持组合语法，例如：`前端 from:jake since:2024-01-01 until:2024-06-30`
5. 在设置中配置 AI（OpenAI 兼容接口）或 WebDAV 后，即可使用「AI 分类」「同步后自动备份」等进阶功能
